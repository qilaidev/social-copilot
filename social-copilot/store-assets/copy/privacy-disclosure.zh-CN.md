数据使用披露：

- 扩展会在你触发生成或分析时，将必要的对话上下文发送到你选择的第三方模型服务或内置模型服务，用于生成候选回复和轻量语气提示。
- 默认只发送最近 N 条消息，并对常见敏感信息进行脱敏与昵称匿名化；这些选项可在设置中调整。
- API Key 默认仅保存在浏览器本地，不会上传到本项目的自建服务器。本项目默认不提供自建后端。
- 若启用远程选择器配置，扩展会从 raw.githubusercontent.com 拉取选择器 JSON；该请求不包含聊天正文和 API Key。
- 诊断导出不包含原文聊天内容和 API Key，仅包含错误码、是否可重试、provider/model、适配器命中摘要等排障字段。
- 本项目不出售用户数据，不将聊天内容用于广告画像。

Social Copilot（聊天导师）是一款面向 Telegram Web、WhatsApp Web、Slack Web 的 AI 回复助手，强调分寸感、效率和隐私控制。你可以在收到消息后快速生成候选回复，查看轻量语气/意图提示后，再决定插入到输入框或复制手动发送。

主要功能：

- 智能回复建议：根据上下文生成多风格候选回复
- 语气/意图提示：识别需要支持、寻求帮助、轻松玩笑或中性语境，仅用于对话辅助
- 思路卡片：推荐共情、解决方案、幽默、中性等回复方向
- 插入与复制：候选回复支持一键填充，也支持复制后手动粘贴
- 本地优先：偏好、画像、诊断数据默认保存在浏览器本地
- 多模型支持：DeepSeek / OpenAI / Claude / NVIDIA / SiliconFlow
- 隐私控制：默认发送前脱敏并限制上下文范围

使用方式：

1. 在扩展设置中选择模型提供商并填写 API Key。
2. 打开 Telegram Web、WhatsApp Web 或 Slack Web。
3. 收到消息时查看建议面板，或按 Alt+S 手动触发。

Social Copilot 不会替你做心理诊断，不会默认自动发送消息，也不会把 API Key 上传到自建服务器。高级自动代理功能默认关闭，开启前需要风险确认，且群聊不会自动发送。
